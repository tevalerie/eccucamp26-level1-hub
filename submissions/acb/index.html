Compliance is architecturally the most conservative voice — it will only state a number that's directly present in retrieved reference data, and cites which fee schedule it came from. Numeric outputs from the loan/mortgage calculator are deterministic Python math (not LLM-generated numbers) and always labeled an estimate.
