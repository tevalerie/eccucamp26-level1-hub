現場上線

一次現場部署因為啟動指令錯誤而失敗，隨即在台上修好。

向下捲動閱讀

第十三天是部署日。從 FastAPI 到 GitHub 再到 Render，現場進行，當著整梯學員的面。

結果失敗了。

My repo failed,（「我的 repo 出錯了」）Python 課程負責人 Nicole Johnson 在過程中說。接著，找到問題之後：your start command is important.（「你的啟動指令很重要。」）

指令寫錯了。就只是這樣——這種錯誤會噴出一整片紅色的輸出，卻幾乎沒告訴你真正的原因；每一個部署過任何東西的工程師，都曾為它賠上一整個下午。她當著所有人的面找到問題、當著所有人的面修好，然後說出了那一天最讓人記得的一句話：my little bot is online. And it is ready to go.（「我的小機器人上線了。而且已經準備就緒。」）

那次失敗的教學價值，遠遠超過一次順利部署的教學價值。一次成功的示範，讓你看到的是順利路徑（happy path）。一次出錯後又修好的示範，讓你看到這份工作真正的樣貌——大部分就是這樣，而且撐得過去。

三週後的成果展上，總評審 Farrell 在台上說了幾乎一樣的話：技術挫折是常態，回饋就是燃料。到那時，好幾支團隊都已經親身經歷過了。
